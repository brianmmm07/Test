# Paper Summaries

This directory contains markdown summaries of arXiv papers, organized by date.

## Structure

```
paper_summaries/
├── YYYY-MM-DD/
│   ├── INDEX.md                    # Index of all papers for that date
│   ├── 1_Paper_Title_One.md       # Individual paper summaries
│   ├── 2_Paper_Title_Two.md
│   └── ...
└── README.md                       # This file
```

## What's Included in Each Summary

Each paper summary markdown file includes:

### 📊 Key Figures (Big Picture)
- Extracted architecture diagrams and overview figures from the PDF
- Visual understanding of the approach

### Overview
- Brief 2-3 sentence summary of the paper

### Key Contributions
- Main contributions and findings (3-5 bullet points)

### Methodology
- Technical approach description

### Key Equations
- **Important mathematical formulations in LaTeX**
- Properly formatted with `$$` for display equations
- Inline equations with `$`
- Full mathematical notation support

### Benchmark Results
- **Performance metrics in tables**
- Quantitative comparisons to baselines
- Dataset names and scores

### Pros & Cons
- **Strengths**: 2-3 advantages of the approach
- **Limitations**: 2-3 potential weaknesses or trade-offs

### Potential Impact
- How the work influences the field

### 🔗 Related Papers
- Top-5 most similar papers with similarity scores
- Based on content similarity computation
- Includes links to PDFs

## Generating Summaries

Use the `generate_summaries.py` script to create summaries:

```bash
# For a specific date
python generate_summaries.py --date 2024-01-15

# For yesterday
python generate_summaries.py --yesterday

# For today
python generate_summaries.py --today

# Custom output directory
python generate_summaries.py --date 2024-01-15 --output my_folder
```

## Use Cases

- **Research review**: Quickly evaluate papers without reading full text
- **Literature survey**: Compare approaches across multiple papers
- **Reference library**: Searchable local collection of summaries
- **Presentation prep**: Extract key points and equations
- **Learning**: Understand technical approaches at a glance
- **Archival**: Keep permanent records of important papers

## Notes

- All equations use LaTeX notation and render in most markdown viewers
- Figures are referenced locally (actual images require PDF extraction)
- Similar papers are computed based on content embeddings
- Summaries are generated by Claude AI based on abstracts
- For full details, always refer to the original paper PDF
